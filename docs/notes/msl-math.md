# MSL double-precision math

The complete retained math range `0x80129CF4..0x8012DAD0` is recovered as 33 original-source-family units. All 15,836 code bytes and 2,256 initialized data bytes match the original after resolving 413 relocations. The `e_log.c` unit also owns eight bytes of uninitialized `zero` storage. All units pass the full DOL hash check and match their owned code and data in the native objdiff report.

The implementations are in `src/MSL/math/`, with one source file per fdlibm unit and a private `fdlibm.h`. Per-unit manifests are `config/GSQE78/candidates/msl-math-*.json`; `scratch/msl_math/handoff.json` lists the complete set and totals. The retained `math_ppc.c` unit contains only the 36-byte `tanf` wrapper emitted from the MSL math API source family. No unused wrapper or hardware assembly routine is counted as matched source.

## Verification and compiler findings

All units use **GC/1.3**, hardware floating point, `-fp_contract on`, `-O4,p`, `-inline auto,deferred`, `-use_lmw_stmw on`, `-pool on`, `-char signed`, `-enum int`, `-str reuse`, `-common off`, and `-Cpp_exceptions off`.

The standard build adds `-i src/MSL/math` for the private header. Zero-sized
compiler pool anchors are recorded separately from the actual array objects;
they do not replace `halF`, `bp`, or `atanhi` in the versioned symbol map.

Three source/compiler details distinguish an exact match:

- Floating contraction produces the original fused multiply-add/subtract instructions. Disabling it changes both polynomial evaluation and the inline square-root iterations.
- Constant pooling shares a base register across the separate arrays in `e_exp.c`, `e_pow.c`, and `s_atan.c`. The original arrays and coefficients remain intact in C.
- `fabs` is an inline wrapper around the compiler's `__fabs` intrinsic. Replacing it with a macro introduces an extra load in `__ieee754_pow`. The full if/else classification helper likewise preserves `ldexp`'s original control flow; a compact ternary rewrite does not.

The older SMS inline double square root has four reciprocal-square-root refinement steps and matches the target's exceptional-value branches. It is retained as C in the private header. No handwritten assembly, instruction words, forced register bindings, or optimization barriers are used.

Run the isolated final-source build and verification with:

```sh
python3 scratch/msl_math/batch_final.py
python3 scratch/msl_math/verify.py e_acos
```

Replace `e_acos` with another stem from `scratch/msl_math/mapping.json`. The complete successful output is saved in `scratch/msl_math/verification.txt`. Each checker run resolves code and data references, compares all initialized allocated sections, checks function size, and writes a per-unit JSON result. BSS is checked for symbol address and extent rather than treated as initialized DOL bytes.

## Ownership

The initialized data is contiguous across these math units: `.rodata` at `0x802ABFA8..0x802AC2F0` (840 bytes) and `.sdata2` at `0x803799A0..0x80379F28` (1,416 bytes). This includes polynomial coefficients, argument-reduction tables, and compiler-generated constants. The logarithm's static `zero` is at `.sbss:0x80377D20..0x80377D28`.

Shared floating limits, `errno`, and other math functions remain normal external references. The preceding console I/O, wide-stream orientation, and environment stub units are separate. The following EXI2/DB hardware code is outside this recovery.

## Provenance

Most fdlibm routines and the declarations follow the preserved [zeldaret/tp references](https://github.com/zeldaret/tp/tree/c8fa8c9e2aab72cf4e5db0e5d1c84a9ea6ee6eb0/libs/PowerPC_EABI_Support/MSL/MSL_C/MSL_Common_Embedded/Math/Double_precision), pinned at `c8fa8c9e2aab72cf4e5db0e5d1c84a9ea6ee6eb0`. They are stored unchanged under `reference/tp-msl/math/`, with hashes in `reference/tp-msl/math/PROVENANCE.md`. The source files preserve the Sun Microsystems permission notices. The TP repository's CC0 notice is retained separately in `reference/tp-msl/LICENSE.md`.

`e_hypot.c`, `s_nextafter.c`, `w_hypot.c`, and `w_log.c` follow the [Netlib fdlibm distribution](https://www.netlib.org/fdlibm/). Unchanged downloads and SHA-256 hashes are under `reference/netlib-fdlibm/`; their Sun permission notices are preserved in each source. The wrappers select the IEEE implementation, matching the retained target behavior.

The inline square root and `fabs` wrappers follow [doldecomp/sms `math.h`](https://github.com/doldecomp/sms/blob/c44637d42e09ec81973c4579e13ece8d0b0f5f58/include/PowerPC_EABI_Support/Msl/MSL_C/MSL_Common/math.h). Classification and `tanf` follow [doldecomp/mkdd `math_api.h`](https://github.com/doldecomp/mkdd/blob/2a9eb75fefd75c649c0488742db931571cbd7812/libs/PowerPC_EABI_Support/include/PowerPC_EABI_Support/MSL_C/MSL_Common/math_api.h); the latter is generated by that source family's `math_ppc.c`. These unchanged community references and repository CC0 notices are preserved under `reference/sms-msl/` and `reference/mkdd-msl/`.

These references establish algorithms and source families, not a claim that ROTFD used those later complete revisions. Compiler behavior, target-specific declarations, retained wrappers, section ownership, and every compiled byte are verified against GSQE78. The original DOL remains unchanged, SHA-1 `5da8295a79bf297ab62c620e6ac66210be1c6ef5`.
