# Surface plane controls research

`fn_802820B4` (384 bytes) and `fn_80282234` (552 bytes) remain private and uncredited. Fresh ordinary source, complete emitted allocation inventories, actual relocation diagnostics, original assembly and failed variants are preserved under `scratch/engine_surface_plane_controls_20261011hd`. Neither function has original exception, constructor or destructor table records. No production or central file changed.

The first checks a material flag, obtains plane coefficients, compares their difference from `(0,0,0,255)` with the external zero vector, then updates the low color byte for `(level+1)^2` vertices with a clamped plane evaluation. Its observed inline equality computes both x and y differences and tests the y difference twice; the source preserves that repeated test. A genuine Vec4 subtraction temporary and member equality preserve the original temporary stores. Declaring the color pointer before the position pointer but initializing positions first closes all GPR differences. The best `update_decl_order.cpp` has the original 384-byte extent, every actual target and all instructions except six floating-point register words: the x subtraction temporary and later y comparison occupy f8/f7 instead of f7/f8. Free subtraction, scalar/reference comparison helpers and a pair member helper do not close them.

The second refreshes a flagged cached inverse matrix, multiplies it by the material basis, transforms `(0,1,0)`, checks the squared magnitude for NaN, and scales the normal by 256 divided by that squared magnitude. It stores the plane normal and negative translated dot product, or `(0,0,0,255)` on the disabled/NaN path. Genuine return-by-value matrix multiplication followed by assignment preserves the original three matrix allocations. Naming the basis reference before inverse refresh closes GPR allocation. A separate dot local preserves the final FNEG instead of contracting it into FNMADD. The best `plane_dot.cpp` has the original 552-byte extent, exact GPRs and actual targets, with fifteen FPR words remaining around persistent one, normal z and scale. Scalar, vector, output-setter and output-constructor forms are preserved; a returned normal helper adds another vector allocation and worsens the result.

Both compile with standard Game options plus `-fp_contract on`; the plane builder also uses `-use_lmw_stmw on`. The constants at 8037B7E8..8037B7FC, existing zero-vector BSS, matrix pool and global remain external and receive no ownership or credit.
