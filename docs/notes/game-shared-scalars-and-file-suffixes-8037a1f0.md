# Shared scalar and file suffix data at 0x8037A1F0

The existing scalar source units now include the native values at `0x8037A1F4..0x8037A200` (the `2π` float and signed-integer-to-double bias), `0x8037A204`, `0x8037A20C`, and the two zero floats at `0x8037A218..0x8037A220`. `src/Game/engine_file_suffix_strings_8037A238.c` owns the three native small-data strings at `0x8037A238..0x8037A250`. Together these additions account for 52 newly matched data bytes. The `lbl_8037A1F8` bias is now a shared source-owned symbol; the two packed-vector conversion functions remain NonMatching because their compiler-generated bias use and floating-point register schedule still differ.

The `0x8037A224..0x8037A238` `.DGC`/`.NGC` block remains original-owned. Its second string is followed by seven zero bytes; the compiler produces only three bytes of natural trailing alignment there, and claiming those as source extent failed the extent audit. The source split leaves the complete 20-byte interval external instead of inventing a padding object. The accepted scalar and string units pass native objdiff, the original DOL SHA-1, regression checks, all 66 tests, and progress extent verification.
