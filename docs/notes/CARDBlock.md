# Dolphin CARD FAT allocation

All six C functions in `CARDBlock.c` match the original `801094E4..801098E8` range: 1,028 bytes, with every relocation resolved and checked against the original DOL. The unit owns no data or BSS. The source follows the retained older Melee SDK reconstruction for obtaining, writing, allocating, freeing, and updating FAT blocks.

The decisive correction was the original FAT representation: `CARDControl.currentFat` and `__CARDGetFatBlock` use opaque `void*`, while this unit views the FAT as a `u16` array. The structured FAT view used by other CARD code has the same memory layout, but applying it at these API boundaries changed register allocation in `__CARDFreeBlock`. The halfword representation yields the original r8/r9 lifetimes without assembly, register forcing, dummy operations, or altered control flow.

The shared CARD ABI now records the opaque pointer and getter return type. `CARDCheck.c` retains its meaningful structured-field accesses through explicit `CARDFatBlock*` views and declares the update function with the matching `u16*` argument. Before changing production files, all 13 previously integrated CARD source units were compiled before and after the ABI correction in isolation. Their allocated code/data/BSS sections, alignment, and symbolic relocations were identical. After applying the production changes, all 13 were compiled again and compared to the preserved original objects, with the same result. The evidence remains under `scratch/CARDBlock/abi_recheck`; `recheck_abi.py` documents the initial experiment and `recheck_production.py` validates the actual shared source state.

The successful compiler is GC/1.2.5n with `-O4,p -inline auto`, normal peephole optimization. `CARDBlock.json` records all six original function ranges and local callback scopes. The isolated production verifier reports `TEXT 1028 1028`. The original source reference and hash are listed in `reference/melee-sdk/PROVENANCE.md`. The integrated source passes full-DOL byte equality and native objdiff checks; all previously integrated CARD units retain their complete matches.
