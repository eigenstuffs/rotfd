# Game command parser

`src/Game/logger_parser.cpp` reconstructs the complete retained function at `0x801FA1F0..0x801FAA0C` (2,076 bytes). It is adjacent to the verified logging methods and operates on the same inferred object storage. The original class/function names and complete translation-unit boundary are unknown; this is a bounded source reconstruction.

The parser recognizes up to 16 arguments, quoted text, decimal numeric tokens with an optional trailing `f`, and case-insensitive boolean words. It handles `#define`, `#set`, `#unset`, `#if`, `#ifnot`, `#else`, and `#endif`, then looks up active commands by name or alias. It calls the registered zero-argument callback and prints help when that callback returns false. The original fixed buffers, unchecked definition/conditional limits, and unmatched-quote behavior are preserved.

The private layout records only observed fields: the command list at offset `0x54`, argument count/pointers at `0x860`/`0x864`, numeric flags/values at `0x8A4`/`0x8B4`, definitions at `0x8F4`/`0x8F8`, and conditional depth/flags at `0xAF8`/`0xAFC`. A command node has 64-byte name, 128-byte help, 16-byte alias, signed-byte callback result, and a next pointer. Names and helper factoring are reconstruction choices.

GC/1.3.2 with `-O4,p -inline deferred -use_lmw_stmw on` reproduces all retained code. Small ordinary inline helpers handle numeric classification, definition lookup/removal, and conditional pushes. Const pointer accessors preserve the observed field reloads. Two one-element constant float tables preserve the addressable `1.0` and `0.0` constants without creating duplicate compiler literals. No inline assembly, register binding, object patching, or masked instruction comparison is used.
