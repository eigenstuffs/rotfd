# MetroTRK transport glue

`src/MetroTRK/dolphin_trk_glue.c` recovers all eleven C functions at 0x8011E1F4..0x8011E5F8 (1,028 bytes), following the [Melee transport glue](https://github.com/doldecomp/melee/blob/master/src/MetroTRK/dolphin_trk_glue.c) and the original target's earlier buffered serial path. The selected transport table, UART initialization, EXI callback, reserve/unreserve calls and board display follow that source family. Hardware ID 1 selects the development-board functions; other values select the AMC EXI2 functions. TRKUARTInterruptHandler is an actual empty function in both reference and target.

This build reads through a receive buffer in chunks capped at 0x110A bytes. TRKReadUART1 returns 4 when there is no available byte and maps a transport read failure to -1. TRKWriteUART1 appends one byte. TRKFlushUART fills the outgoing buffer with zero bytes up to a minimum length of 2,048, writes the buffered bytes, resets the count, and maps nonzero transport status to -1. It preserves the original unconditional minimum-length write behavior. An ordinary for-loop counter update and negated comparison for the return status reproduce the original compiler allocation. The read routine uses a local pointer to its shared state, matching the original retained base register. No assembly substitutes are used.

The source owns the seven-entry gDBCommTable, 28 initialized zero bytes at 0x802CFE90..0x802CFEAC with alignment 8. The original four-byte alignment gap to 0x802CFEB0 is external padding. The table and TRKEXICallBack are compiler-local. The callback calls the original TRKLoadContext assembly routine at 0x8011E16C..0x8011E1F4, which remains fallback and outside C coverage.

UART mutable storage remains original fallback at 0x8033B010 and 0x8033C12C. A private ABI view records the three observed counters and the receive buffer at offset 0x10; the word at offset 0x0C has no observed use in these routines and is explicitly unresolved. The source does not allocate this view or claim unknown storage as recovered BSS. Both external storage identities must be global for linkage. No shared TRK header was modified.

GC/1.3.2 with `-inline auto,deferred` and the ordinary MetroTRK flags reproduces all 1,028 text bytes, all relocations and the 28 initialized table bytes. The reference's peephole-off pragma is retained narrowly on TRK_board_display to preserve its actual variadic OSReport call. The complete manifest is config/GSQE78/candidates/MetroTRK-dolphin_trk_glue.json; the isolated compile and verification scripts are under scratch/MetroTRK. The integrated source passes whole-DOL byte equality, native objdiff code/data checks, and the original-source regression audit.
