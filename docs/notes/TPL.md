# Texture-palette descriptor getter

`src/dolphin/tpl/TPL.c` reproduces all 16 bytes at `0x80117B34..0x80117B44`. The original loads the pointer at object offset 8 and returns the address of its eight-byte entry at the supplied index. GC/1.2.5n with the normal SDK flags emits exactly the four original instructions. The source owns no data, BSS, exception records, or relocations.

The `TPLGet` identity is an inference from the SDK location immediately after GX and before MetroTRK, the twelve-byte palette header, and its eight-byte descriptors containing texture/CLUT header pointers. The pinned [OGWS TPL declarations](https://github.com/doldecomp/ogws/blob/5b6aee89ad1162e6767697acfe7afc551adb4cde/include/revolution/TPL/TPL.h) corroborate those structures and the signature. Its [later TPL getter](https://github.com/doldecomp/ogws/blob/5b6aee89ad1162e6767697acfe7afc551adb4cde/src/revolution/TPL/TPL.c) additionally reduces the index modulo the descriptor count. The target has no load from offset 4 and no modulo operation, so the reconstructed body preserves direct indexing. No debug assertion, bounds check, or newer behavior is added. The exact original source filename and SDK revision are not independently established from this four-instruction function.

The manifest preserves `fn_80117B34` as the original name and explicitly records this attribution uncertainty; the integrated symbol is `TPLGet`. `scratch/TPL/verify.py` compiles the C source and verifies its entire allocated ELF text against the protected original DOL. The full-DOL SHA-1 and native objdiff pass with all 16 bytes linked from C. The untouched source/header reference, commit, hashes, and license are preserved under `reference/ogws-sdk`.
