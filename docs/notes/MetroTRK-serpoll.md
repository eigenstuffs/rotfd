# MetroTRK serial input and framing

`src/MetroTRK/serpoll.c` recovers all five linked C functions at 0x80118BEC..0x80118FB8 (972 code bytes): TRKTerminateSerialHandler, TRKInitializeSerialHandler, TRKProcessInput, TRKGetInput and TRKTestForPacket.

The [Melee reference](https://github.com/doldecomp/melee/blob/master/src/MetroTRK/serpoll.c) supplies event dispatch, serial initialization and the FramingState layout. This target's full frame parser is reconstructed from its original control flow rather than the reference's block-read shortcut. It recognizes 0x7E delimiters, unescapes 0x7D-prefixed bytes with XOR 0x20, rejects an escape immediately before the closing delimiter, and rejects frames shorter than two bytes. It strips the final checksum byte and resets the buffer position before delivering a complete packet. The target updates fFCS but contains no final checksum comparison; the source preserves that observed behavior. Buffer cleanup and validation are ordinary inline C helpers.

The unit owns .bss:0x8033AA58..0x8033AA70 (24 bytes, alignment 8): the global 4-byte gTRKInputPendingPtr followed by the private 20-byte gTRKFramingState. The latter contains a buffer ID, buffer pointer, receive-state byte, 32-bit escape flag and checksum byte, including its required internal alignment. No initialized data is owned. Declaration order accommodates the compiler's deferred generation; there are no artificial padding objects.

GC/1.3.2 with `-proc gekko -fp hardware -enum int -str reuse -common off -O4,p -inline auto,deferred -sdata 0 -sdata2 0 -pool off -use_lmw_stmw on -rostr -i src/MetroTRK -Cpp_exceptions off` reproduces all 972 bytes after relocation against the original DOL. The successful-frame source resets the ID before the pointer; the compiler emits the original pointer-first store sequence. This statement order resolves the final register allocation difference without volatile or assembly. Scripts and complete symbol identities are under `scratch/MetroTRK` and the candidate manifest. The shared TRK ABI is unchanged since the verified message-buffer handoff. Full-DOL and native objdiff remain integration checks.
