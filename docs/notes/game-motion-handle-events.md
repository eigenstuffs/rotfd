# Motion Handle event variants

Accepted matching source: the production build passes the original DOL hash,
strict allocated-byte/extent and actual-relocation checks, baseline regression
checks, generated progress verification and all 26 repository tests.

Eleven ordinary C++ functions reconstruct 1,540 text bytes and 220 owned exception/index bytes. Each resolves the actor Handle at offset 0x24, sends original event 0x8D with its observed input/state mask and then calls the original phase method. Masks are 1, 0x0C, 0x20 or 0x10. The final phase targets remain their existing native symbols.

The shared views preserve signed Handle index and generation behavior, 16-byte manager entries and original context offset 0x118. Strict production recompilation verifies every allocated byte, symbol extent, actual relocation and compiler-local exception/index record. Full original exception-index/descriptor and constructor/destructor tables are audited.

These are partial text-only splits. Original class tables, other methods and data remain outside them. No weak helpers, owned data/BSS/padding, aliases, raw payload edits or symbol migrations are introduced. The shared declarations have eleven consumers. Frozen isolated evidence is in `scratch/game_motion_handle_events/final_integration.json`; complete central original-DOL acceptance is required.
