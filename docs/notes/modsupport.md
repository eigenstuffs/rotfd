# Module support (`Python/modsupport.c`)

`src/Python/modsupport.c` reconstructs the five functions in the complete
linked module-support unit. All 4,720 code bytes and 800 initialized data
bytes match the original DOL after applying 254 ELF relocations. The
four-byte package-context pointer lies within the original zero-initialized
range. Whole-program integration is a separate main-build check.

| Section | Original range | Bytes |
| --- | --- | ---: |
| `.text` | `8019E6A4..8019F914` | 4,720 |
| `.data` | `802E2DD0..802E30E8` | 792 |
| `.sdata` | `80376FB8..80376FC0` | 8 |
| `.sbss` | `80377F30..80377F34` | 4 |

The reference is the official `reference/cpython-2.1/Python/modsupport.c`,
with its license retained at `reference/cpython-2.1/LICENSE`. The five linked
functions are `Py_VaBuildValue`, `Py_BuildValue`, `do_mkvalue`, `do_mkdict`,
and `Py_InitModule4`. `countformat`, `_ustrlen`, `do_mktuple`, and `do_mklist`
are inline-only helpers. The un-emitted public call and module-add helpers
are omitted.

The recovered configuration uses Python C API version 1010, 16-bit Unicode
characters, native long-long support, complex-number support, and an
array-based 12-byte PowerPC `va_list`. The same Metrowerks variadic interface
verified in `errors.c` reproduces both build-value entry points. Compiler
settings are GC/2.0 with `-opt level=4,nopeephole,speed`,
`-inline auto,deferred`, and `-pool off`.

The 115-entry jump table at `802E2EEC..802E30B8` is generated by the C
format-parser switch. Every relocated entry is exact. The current object
calls it `@480`; the original generated symbol is `jumptable_802E2EEC`.
The source contains no manually supplied jump addresses or instruction data.

`_Py_PackageContext` owns exactly four bytes at `80377F30`; the old generated
eight-byte label also covered `80377F34..80377F38`, which must remain separate
padding. `config/GSQE78/candidates/modsupport.json` records this correction,
the complete mappings, and source/object hashes.

```sh
python3 scratch/modsupport/verify.py
```

The check recompiles the source, validates the original DOL hash, rejects
unexpected allocated sections and size changes, applies every relocation,
and compares every code and initialized data byte. BSS placement is checked
against the original zero-initialized region. Nothing is masked to obtain
the match; source credit requires the registered full DOL build to pass.
